# Python - Arquivos e Modularização

Exercícios desenvolvidos em Python para a disciplina de Sistemas Operacionais.

## Exercícios

- Exercício 01: Calcular o quadrado dos números de 10 a 150 e gravar em um arquivo.
- Exercício 02: Gerar a sequência de Fibonacci e armazenar os termos em um arquivo.
- Exercício 03: Ler o arquivo de Fibonacci e exibir apenas os números ímpares.

## Objetivo

Praticar a utilização de funções, procedimentos, estruturas de repetição e manipulação de arquivos em Python.

## Tecnologia utilizada

- Python 3
